# 本地来源契约

首页提供城市与年度选择、SVG 图表、悬浮提示与说明 iframe。来源内部 /chart、/note 请求属于页面实现，不是允许直连的数据接口。产品只通过真实页面交互取数，不读取 JS 变量、源码或内部接口。可见图层 data-revision 与说明文字表达当前口径；标题先变化，图层异步更新，仍在途的旧请求也可能迟到，页面不替使用者保证三处同时完成。
2024 年包括建筑零值、交通缺报、工业观测，2023 年的部门数量和顺序不同。点位有可见部门标签，悬浮后展示观测及其显示口径；点击工业明细打开新页面，其范围是重点企业且单位不同，总图为全市终端能源。城市与年份均可反复选择，刷新浏览器会回到默认选择。来源仅用于授权本地交互，不连接真实统计门户。

演练来源由 Python 标准库 HTTP 服务启动，默认端口 8765。GET /health 可查询来源时间与阶段；POST /__admin/advance 接收 seconds、phase 推进本地情形；GET /__admin/log 回查实际请求。这些控制只供操作员调试来源，不能替代产品从正常入口取得资料。来源进程重启会清空其演练状态；采集端自己的保存目录由产品独立管理。
